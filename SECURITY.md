# Security policy

Tungsten has no public release.
Report vulnerabilities affecting the current default branch through [private vulnerability reporting](https://github.com/P4suta/Tungsten/security/advisories/new).
Include the affected revision, reproduction steps, observed impact, and relevant deployment conditions.
Keep credentials and personal notes out of reports.

The service trusts devices that can reach its listener and stores readable content.
The [security boundaries](docs/security.md) describe the intended deployment and protections.
Use ordinary issues for defects that don't expose sensitive content or violate those boundaries.
